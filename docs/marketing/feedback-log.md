# cc-clip Beta Promotion Feedback Log

Use this after any approved public action. The goal is to capture useful
signals without turning every reply into a support debate.

## Rules

- Record facts, not impressions.
- Link to the source when possible.
- Separate cc-clip bugs from upstream-tool discussion.
- If a maintainer or moderator asks to stop, mark the thread closed and do not
  keep replying.
- If the same problem appears twice, pause promotion and open a docs or code
  follow-up.
